# Finanzas de la casa

Aplicación web simple para llevar las finanzas del hogar desde el celular: registrar ingresos y gastos, controlar cuentas por pagar (luz, agua, etc.) y fijar un presupuesto mensual por categoría.

No necesita instalación ni servidor: es un solo archivo (`index.html`) que funciona directo en el navegador. Los datos se guardan en el propio celular (localStorage), por lo que quedan solo en ese navegador/dispositivo.

## Cómo usarla
Entra al link de GitHub Pages de este repositorio y, si quieres, agrégala a la pantalla de inicio de tu celular para que se abra como una app.
